Korean LLM Quantization Pipeline Builder

H. Choi
Independent Research / Study

This ongoing project focuses on morpheme-aware post-training quantization for Korean LLMs. The work centers on building and documenting a practical workflow for calibration-set design, low-bit PTQ experiments, and evaluation on Korean-language models.

GitHub
Focus. This project explores how Korean morphological structure can be reflected in calibration data for post-training quantization, with the goal of making quantization experiments more language-aware and easier to analyze.

What I Built

  • Built the project around morpheme-aware calibration data for Korean LLM post-training quantization
  • Structured a repeatable workflow for model preparation, quantization experiments, and result comparison
  • Documented implementation choices and experiment setup in a public GitHub repository
  • Connected the project with related technical writing on Korean LLM efficiency and on-device AI

Key Engineering Questions

Calibration Quality

How should Korean prompts be curated so calibration reflects actual morphology and language usage patterns?

Evaluation Consistency

How can quantized and original models be compared with a repeatable process instead of anecdotal prompting?

Language-Aware PTQ

What changes when Korean-specific linguistic structure is considered during post-training quantization?

Why It Matters

This project is part of a broader effort to turn study notes and experiments into public, reproducible work. It also helps connect my interests in deep learning systems, Korean-language modeling, and engineering documentation.
